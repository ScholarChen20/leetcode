## 项目定位

**OmniRad** —— 一个面向医学影像（超声为主）的**多模态统一多任务模型**：单条 LLM 流水线同时完成分割、检测、指代定位、报告生成、识别 5 类任务，并输出可后处理成图的结构化结果（掩码 / 框），而非纯文本。

## 核心贡献

1. **统一的多任务架构**：图像 + 文本统一 embedding 送入一个 LLaMA-2-7B（LoRA），用「任务标识符」切换任务、用「特殊 token 数量」决定输出规模，无需为每个任务训练独立模型。

2. **SAM 深度集成**：LLM 的 hidden state 经 `seg_projector`（MLP）映射到 SAM 的 sparse-prompt 空间，直接驱动 SAM mask decoder 产出像素级分割——解决了"语言模型只会说、不会画"的根本问题。

3. **多尺度检测**：`<BOX_S/M/L>` 三档 + 尺度感知损失（小目标 3×、中 1.5×、大 1×），针对性缓解医学小病灶漏检。

4. **几何一致性损失**：分割掩码的紧包围框与检测框做 L1 对齐，让分割/检测两分支**互相监督**，实现多任务协同增益。

5. **不确定性建模**：异方差（heteroscedastic）损失，输出逐像素不确定度。

6. **工程健壮性**：FP32 手动 CE、非法 label 清洗、logits clamp、NaN/Inf 梯度拦截、二次前向解码——保证大规模训练不炸不卡。

## 差异化创新点（相对 MiniGPT-v2 基线）

| 维度 | 原版 MiniGPT-v2 | OmniRad |
|---|---|---|
| 任务 | 文本 VQA / 有限 grounding | 5 类任务统一（含分割/检测/定位/报告） |
| 输出 | 离散 token（框用坐标字符串） | **结构化几何输出**（掩码张量 + 框 dict） |
| 分割 | ❌ 不支持 | ✅ 借力 SAM 的像素级掩码 |
| 检测 | 单一尺度 | 三尺度 + 尺度加权 |
| 多任务协同 | 无 | mask↔box 一致性约束 |
| 后处理 | 需自己解析字符串 | 直接返回可视化就绪的结果 |

## 一句话总结

**贡献**：把「只能对话」的医学多模态大模型，升级成「能看、能说、能定位、能分割」的统一结构化解码框架；**创新点**在于——用「特殊 token 路由 + SAM 借力 + 几何一致性」三招，让一个语言模型主干以可训练、可监督的方式产出**可变数量的像素级/坐标级**输出，这是相对基线的本质区别。
