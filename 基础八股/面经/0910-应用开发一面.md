### 项目/实习经历
1) 实习中，从一个需求到开发到交付过程，你的职责、解决策略，结合具体的例子
> 答：按流程讲一遍，每步都说清"我做了什么决策"：对齐背景与验收标准 → 方案设计（接口契约、数据模型、异常与超时、性能预估）→ 拆任务排期 → 开发自测（单测 + 边界用例）→ 联调 → 测试回归 → 灰度上线 → 看指标复盘。例子挑一个有转折的，比如"原方案同步调用会超时，改成异步 + 回调，P99 从 3s 降到 400ms"。

2) 擅长的编程语言，python中的异步机制了解吗
> 答：Python 是单线程事件循环 + 协程：async def 定义协程，await 在 IO 等待处让出控制权，事件循环去调度其他就绪任务，所以一个线程能扛大量并发 IO。三个要点：不能有阻塞调用（要 run_in_executor 或换异步库）、CPU 密集仍要用进程池、异步生态要全链路异步（有一个同步库就白搭）。

3) python中的装饰器了解多少
> 装饰器是一种函数增强机制，可以复用公共逻辑，并保持原函数代码不变。
> 补充：本质是"接收函数、返回函数"的高阶函数，@ 只是语法糖。实现要点——用 functools.wraps 保留 __name__/__doc__；带参数装饰器要多一层闭包；类装饰器实现 __call__；典型用途是日志、计时、缓存、鉴权、重试。

4) 哈希表了解吗
> 答：以 key 直接计算出存储位置的数据结构，平均 O(1) 查找、插入、删除。三个组成部分：哈希函数（把 key 映射成下标）、桶数组（存数据的容器）、冲突处理机制（不同 key 落到同一位置时怎么办）。最坏情况退化成链表是 O(n)，所以需要好的哈希函数和扩容策略。

5) 哈希表如何建立
> 答：①确定初始容量（通常取 2 的幂，方便用位运算代替取模）；②对 key 做哈希并扰动（如 Java 的 h ^ (h >>> 16)），再映射到下标；③冲突用链地址法（链表，长了转红黑树）或开放寻址法（线性/二次探测）；④维护负载因子（如 0.75），超过阈值就把容量翻倍并 rehash 迁移数据。

6) 计算机网络层结构了，TCP/IP四层结构有啥（网络接口层/网络层/传输层/应用层）
> 答：四层——网络接口层（链路层，帧与 MAC，负责相邻节点传输）、网络层（IP 寻址与路由，尽力而为）、传输层（TCP 可靠有序、UDP 快但不保证）、应用层（HTTP/DNS/WebSocket 等）。对应 OSI 七层是把会话层和表示层并入应用层、数据链路层与物理层并入网络接口层。

7) SprintBoot框架的项目开发过吗，什么是依赖注入
> 答：依赖注入（DI）是控制反转的实现方式：对象不自己 new 依赖，而由容器创建好再注入进来（构造器注入 / Setter 注入 / 字段注入）。好处是解耦（依赖接口不依赖实现）、易替换、易测试（注入 mock）、生命周期由容器统一管理。实践中推荐构造器注入——依赖不可变、必填项明确、循环依赖能提前暴露。

8) FastGPT平台是什么
> 答：开源的知识库问答与 AI 应用编排平台：支持文档导入与向量化、混合检索与重排、可视化 Flow 编排（LLM 节点、检索节点、条件分支）、对外发布 API。适合快速搭 RAG 类应用；需要深度定制（自定义工具协议、复杂状态机、评测闭环）时还是要落到代码层。

9) python是什么类型语言
> Python 解释器是 Python 程序的运行环境，负责把 Python 代码转换并执行，同时管理程序运行所需的对象、内存和异常。
> 补充标签：动态类型（运行时才确定类型）、强类型（不会隐式做不相容的转换）、解释型（先编译为字节码再由 CPython 虚拟机执行）、面向对象且支持多范式、有 GIL 所以多线程不能并行跑 CPU 密集任务。

### 古法编程
1) 数字炸弹
随机生成1-100的随机数，每次用户输入两个数，每次输出和哪个数更靠近，如果相同就退出
> 答：核心就是"比较距离 + 终止条件"。随机生成 target，循环读入两个数 a、b，比较 |a-target| 与 |b-target| 输出谁更近，相等则结束。要注意：输入合法性校验（非数字、超范围）、相同数但都不等于 target 的边界（题面说"相同就退出"，实现时明确是"两数相等"还是"某数命中 target"）、以及历史猜测记录。

2) 如何快速定位到这个随机数（二分）
> 答：每轮取当前区间中点 mid 去猜，根据"更近"的反馈把区间砍半——猜的值比 target 小就抬高下界，大就压低上界，O(log n) 次（100 以内 7 次）。本质是把"距离比较"转成"大小比较"，前提是反馈能判断方向；如果题面只给"哪个更接近"，就一次问两个点（mid-1 和 mid+1）来构造方向信息。

3) 实例中的场景，面向对象场景下，你会定义哪些类
> 答：拆成职责单一的类——Game（主流程与状态机）、TargetGenerator（生成随机数，可注入便于测试）、Guesser（猜测策略接口，二分实现、随机实现可替换）、Judge（比较距离并给出反馈）、GuessRecord（历史记录与统计）、InputValidator（输入校验）。体现两个设计点：策略模式让算法可替换，依赖注入让随机源可 mock，方便写单测。
