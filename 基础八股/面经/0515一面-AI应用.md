## AI应用

1. 自我介绍
> （略）30 秒：学校/专业 + 一段最相关的项目（负责哪块、量化结果）+ 技术栈关键词 + 投递理由。

2. 日常八股
1) 了解python的多线程吗
> 答：有 GIL，同一时刻只有一个线程执行字节码，所以多线程适合 IO 密集（网络、文件、调用大模型接口），CPU 密集要用多进程绕开 GIL，高并发 IO 用 asyncio 协程更省资源。线程间通信用 Queue，共享可变状态要加锁。

2) python的lambda了解吗
> 答：匿名的单表达式函数，常用于 sorted 的 key、map/filter、回调。两个坑：闭包延迟绑定（循环里创建的 lambda 取到的是最后一个值，用默认参数 x=i 固化）、只能写表达式没法写语句。复杂逻辑还是用 def，方便调试和加类型标注。

3) except机制了解吗
> 答：try / except / else / finally：except 按顺序匹配第一个符合的异常，else 在无异常时执行，finally 一定执行用于释放资源。最佳实践是捕获具体异常而不是裸 except、用 raise ... from e 保留原始原因、用 with 管理资源、不要拿异常做流程控制。

4) 讲解下transformer的结构
> 答：每层 = 多头自注意力（建模 token 关系）+ FFN（逐位置非线性变换），外套残差和 LayerNorm，输入加位置编码。Decoder 用因果掩码保证只能看前文，并可加交叉注意力。要点补充：自注意力的 Q/K/V 与缩放点积、多头是为在不同子空间学不同关系、LayerNorm 比 BatchNorm 更适合变长序列。

5) 讲下你项目中向量数据库的使用
> 答：文档切片（按语义/标题层级，带元数据）→ Embedding（bge-m3 等）→ 写入 Milvus 或 pgvector，建 HNSW 索引（M、efConstruction 调参）→ 查询时向量召回 Top-K + 标量过滤（租户/时间/权限）→ 交给 rerank 精排再拼 prompt。增量更新按 doc_id 覆盖写，删除用软删 + 定期 compaction 回收。

3. 项目经历
1) 你做的项目中你认为遇到的最难的场景是什么
> 答：选题原则——选技术上有取舍的，不要选"加班赶进度"。示范：多轮 Agent 上下文爆炸导致效果反而下降。讲法：现象（第 10 轮后答非所问、token 成本翻倍）→ 定位（打点看每轮 token 分布，发现工具返回占 70%）→ 方案（工具结果裁剪 + 早期轮次摘要 + 关键事实落结构化 KV）→ 结果（token 降 6 成，任务完成率还涨了）→ 反思（一开始就该在工具层限长，而不是在 prompt 里求模型忽略）。

2) 举例说下你项目中遇到的问题和如何解决的
> 答：统一用 STAR-L：场景 → 任务 → 我的动作（技术细节要具体到参数/阈值）→ 结果（必须量化）→ 反思。常见可讲的三个：LLM 输出格式不稳定（改原生 Function Call + schema 校验 + fallback，失败率 15%→1%）、Agent 死循环（重复动作检测 + 最大步数 + reflection）、检索召回低（混合检索 + rerank + 分块改造）。

3) 多智能体协同是怎么实现的
> 答：主 Agent 做分解与分发（hub-and-spoke），子 Agent 各有专属 prompt 与工具集，结果摘要后回传主 Agent 汇总；需要并行的用并发调度 + 合并节点，需要先后依赖的用 pipeline 串联。关键设计：Agent 间传结构化结果而不是全量上下文（否则上下文爆炸）；失败时主 Agent 重试或换策略重新分配；用共享状态（blackboard）解决需要共同读写同一份数据的场景。

4. 手撕
字符串解码（单调栈思路）
> 答：单栈存 (前缀字符串, 重复次数)。遇数字累积成多位数；遇 '[' 把当前串和倍数压栈并重置；遇 ']' 弹出得到 last 和 k，令 cur = last + cur * k；遇字母直接追加。时间 O(n)，空间 O(嵌套深度)。易错点：数字可能是多位、嵌套需要靠栈回溯、末尾没有 ']' 时直接输出即可。
>
> ```python
> def decodeString(s: str) -> str:
>     stack, cur, num = [], "", 0
>     for ch in s:
>         if ch.isdigit():
>             num = num * 10 + int(ch)
>         elif ch == '[':
>             stack.append((cur, num))
>             cur, num = "", 0
>         elif ch == ']':
>             pre, k = stack.pop()
>             cur = pre + cur * k
>         else:
>             cur += ch
>     return cur
> ```
