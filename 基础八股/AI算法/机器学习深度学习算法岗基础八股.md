## 一、机器学习基础

### Q1. 什么是偏差和方差？

- **偏差高**：模型过于简单，训练集和测试集都不好，容易欠拟合。
- **方差高**：模型过于复杂，训练集很好但测试集差，容易过拟合。
- 实际目标是在偏差和方差之间取得平衡。

### Q2. 如何解决过拟合？

常用方法：

```text
增加数据
数据增强
L1/L2 正则化
Dropout
降低模型复杂度
Early Stopping
交叉验证
```

### Q3. L1 和 L2 正则化有什么区别？

- `L1` 会让部分参数变成 0，可以做特征选择。
- `L2` 会让参数整体变小，但通常不会变成 0，可以提高模型稳定性。

### Q4. 训练集、验证集、测试集分别做什么？

- 训练集：学习模型参数。
- 验证集：选择模型和调整超参数。
- 测试集：最终评估模型泛化能力。

测试集不能参与训练和调参，否则会造成评测泄漏。

### Q5. 什么是数据泄漏？

训练时使用了线上不可获得的信息，或者把测试集信息带入训练过程。

例如：

```text
先用全量数据做标准化，再划分训练集和测试集
使用未来时间的数据预测过去
把标签信息放进特征
```

### Q6. Accuracy、Precision、Recall、F1 怎么区别？

- `Accuracy`：整体预测正确的比例。
- `Precision`：预测为正的样本中，有多少是真正的正样本。
- `Recall`：真实正样本中，有多少被找出来。
- `F1`：Precision 和 Recall 的调和平均。

正负样本不均衡时，不能只看 Accuracy。

### Q7. ROC-AUC 和 PR-AUC 有什么区别？

- `ROC-AUC` 衡量正负样本整体排序能力。
- `PR-AUC` 更关注正类识别效果。
- 正样本很少时，通常 `PR-AUC` 更有参考价值。

### Q8. 类别不平衡怎么处理？

```text
过采样少数类
欠采样多数类
类别加权
Focal Loss
调整分类阈值
使用 Precision、Recall、F1、PR-AUC 评估
```

### Q9. 标准化和归一化有什么区别？

- 归一化：把数据缩放到固定范围，例如 `[0, 1]`。
- 标准化：减均值、除标准差，使数据均值接近 0、方差接近 1。

线性模型、SVM、KNN、神经网络通常对特征尺度比较敏感。

### Q10. 为什么需要交叉验证？

把数据划分成多组，轮流使用训练集和验证集，减少一次划分带来的偶然性，更稳定地评估模型。

## 二、经典机器学习算法

### Q11. 逻辑回归的原理是什么？

逻辑回归先计算线性结果：

```text
z = wx + b
```

再通过 Sigmoid 转成概率：

```text
p = sigmoid(z)
```

二分类通常使用交叉熵损失，通过梯度下降学习参数。

### Q12. 决策树如何选择划分特征？

分类树通常使用：

- 信息增益；
- 信息增益率；
- Gini 系数。

回归树通常使用均方误差。目标都是让划分后的子节点更纯。

### Q13. 随机森林为什么不容易过拟合？

随机森林通过随机采样训练数据、随机选择部分特征，训练多棵决策树，最后进行投票或平均。多个弱相关模型组合后，可以降低方差，提高泛化能力。

### Q14. GBDT 的核心思想是什么？

GBDT 不是独立训练多棵树，而是每一轮拟合上一轮的残差或负梯度，逐步修正前面模型的错误。

### Q15. XGBoost 和 GBDT 有什么区别？

`XGBoost` 是 GBDT 的工程优化版本，主要增强包括：

- 使用一阶和二阶梯度；
- 增加正则化；
- 支持并行和缺失值处理；
- 工程性能更好。

### Q16. LightGBM 为什么训练速度快？

主要使用 Histogram 直方图算法、Leaf-wise 生长策略、特征和数据压缩等方法，适合大规模数据。Leaf-wise 更容易过拟合，需要限制树深和叶子数。

### Q17. SVM 的核心思想是什么？

SVM 通过寻找一个分类超平面，让两类样本之间的间隔最大。对于非线性问题，可以通过核函数映射到高维空间。

### Q18. K-Means 的流程是什么？

```text
随机初始化 K 个中心
→ 分配样本到最近中心
→ 重新计算中心
→ 重复上述过程直到收敛
```

缺点是需要预先指定 K，并且对初始中心和异常点比较敏感。

### Q19. PCA 的作用是什么？

PCA 通过线性变换找到数据方差最大的方向，用少量主成分表示原始数据，常用于降维、去噪、可视化和缓解特征共线性。

## 三、深度学习基础

### Q20. 反向传播的原理是什么？

先进行前向计算得到损失，再根据链式法则从后向前计算梯度，最后使用优化器更新参数。

### Q21. 梯度消失和梯度爆炸怎么解决？

```text
合理初始化
使用 ReLU/GELU
使用残差连接
使用 BatchNorm/LayerNorm
梯度裁剪
使用合适的学习率
```

### Q22. ReLU 为什么常用？有什么问题？

ReLU 计算简单、可以缓解梯度消失：

```text
ReLU(x) = max(0, x)
```

问题是负数区域梯度为 0，可能出现“神经元死亡”。可以使用 LeakyReLU、GELU 等改进。

### Q23. BatchNorm 和 LayerNorm 有什么区别？

- `BatchNorm`：按 Batch 维度统计均值和方差，依赖 Batch 大小。
- `LayerNorm`：对单个样本的特征维度归一化，不依赖 Batch。

CNN 中常用 BatchNorm，Transformer 中通常使用 LayerNorm 或 RMSNorm。

### Q24. SGD 和 Adam 有什么区别？

- `SGD`：更新简单，泛化能力通常较好，但对学习率敏感。
- `Adam`：结合一阶矩和二阶矩，自适应调整学习率，收敛更快，使用更方便。

大模型训练中常见 `AdamW`，它把权重衰减与梯度更新解耦。

### Q25. 常见学习率策略有哪些？

```text
Warmup
Step Decay
Cosine Decay
Linear Decay
OneCycle
```

大模型训练通常使用 Warmup 加 Cosine 或 Linear Decay，避免训练初期不稳定。

### Q26. Dropout 的作用是什么？

训练时随机丢弃部分神经元，减少模型对单个特征的依赖，缓解过拟合。推理时关闭 Dropout。

### Q27. 残差连接为什么有效？

残差连接让网络学习：

```text
F(x) + x
```

可以缓解深层网络的梯度消失和网络退化问题，使深层模型更容易训练。

### Q28. CNN 为什么适合处理图像？

CNN 具有局部感受野、参数共享和平移不变性，可以通过多层网络提取从边缘到语义的特征。

### Q29. RNN、LSTM、GRU 有什么区别？

- `RNN`：结构简单，但容易梯度消失。
- `LSTM`：通过门控机制保留长期信息。
- `GRU`：结构比 LSTM 简单，参数更少。

现在长文本任务通常更多使用 Transformer。

### Q30. Attention 的公式是什么？

```text
Attention(Q, K, V) = Softmax(QKᵀ / √d)V
```

- `Q`：当前要查询什么；
- `K`：各位置的匹配特征；
- `V`：最终聚合的信息；
- 除以 `√d` 是为了防止点积过大导致 Softmax 梯度不稳定。

### Q31. Transformer 为什么比 RNN 更适合长序列？

Transformer 可以并行计算整个序列，训练效率高；Self-Attention 可以直接建立任意两个位置之间的关系，长距离依赖能力更强。

### Q32. 为什么需要位置编码？

Self-Attention 本身不感知 Token 顺序，需要加入位置信息。常见方法有 Sinusoidal Position Encoding、Learned Position Embedding 和 RoPE。

### Q33. Causal Mask 是什么？

在生成式模型中，当前位置不能看到未来 Token。Causal Mask 会屏蔽上三角区域，保证模型按照从左到右的方式生成。

### Q34. 训练模式和推理模式有什么区别？

训练模式会启用 Dropout，并使用 BatchNorm 的当前 Batch 统计量；推理模式关闭 Dropout，并使用固定的运行统计量。

## 四、计算机视觉方向

### Q35. IoU 是什么？

IoU 是预测框和真实框的交并比：

```text
IoU = 交集面积 / 并集面积
```

用于判断检测框是否匹配真实目标。

### Q36. NMS 的作用是什么？

NMS 用于去除同一个目标产生的多个重复框：

```text
按置信度排序
→ 保留最高分框
→ 删除与它 IoU 过高的框
→ 重复执行
```

### Q37. mAP 如何计算？

先根据 IoU 判断 TP/FP，再画出 Precision-Recall 曲线，计算每个类别的 AP，最后对所有类别取平均得到 mAP。

### Q38. 一阶段和两阶段目标检测有什么区别？

- 一阶段：直接预测类别和位置，例如 YOLO，速度快。
- 两阶段：先生成候选框，再分类和回归，例如 Faster R-CNN，通常精度更高但速度更慢。

### Q39. 语义分割、实例分割和全景分割有什么区别？

- 语义分割：区分每个像素的类别，不区分同类个体。
- 实例分割：区分同一类别中的不同对象。
- 全景分割：同时处理背景区域和独立目标。

### Q40. 小目标检测为什么困难？

小目标像素少、特征弱，经过多次下采样后容易丢失。常用提高输入分辨率、使用多尺度特征、增加小目标样本和优化特征融合等方法。

## 五、NLP 与大模型基础

### Q41. Tokenizer 和 Embedding 分别做什么？

- `Tokenizer`：把文本切分成 Token，并转换成 Token ID。
- `Embedding`：把 Token ID 映射成向量。

流程是：

```text
文本 → Tokenizer → Token ID → Embedding 向量
```

### Q42. BERT 和 GPT 有什么区别？

- `BERT`：双向编码，适合理解任务，如分类、抽取、匹配。
- `GPT`：单向自回归生成，适合文本生成和对话。

### Q43. 预训练、SFT、LoRA 分别是什么？

- 预训练：从海量文本中学习通用能力。
- `SFT`：用指令数据训练模型遵循任务要求。
- `LoRA`：只训练低秩适配器，降低微调显存和成本。

### Q44. RAG 的基本流程是什么？

```text
文档切分
→ Embedding 建索引
→ 用户问题向量化
→ 召回相关文档
→ Reranker 精排
→ LLM 根据上下文生成答案
```

### Q45. Embedding 和 Reranker 有什么区别？

- `Embedding`：把 Query 和文档转为向量，用于快速召回。
- `Reranker`：对召回的少量候选文档重新精排，准确性通常更高，但计算成本也更大。

### Q46. KV Cache 是什么？

自回归生成时，历史 Token 的 Key 和 Value 不需要重复计算。KV Cache 把它们缓存下来，后续只计算新 Token，可以显著加快 Decode，但会增加显存占用。

### Q47. Prefill 和 Decode 分别是什么？

- `Prefill`：一次处理完整 Prompt，偏计算密集型。
- `Decode`：逐 Token 生成，偏显存带宽和访存密集型。

### Q48. 如何评估大模型回答质量？

至少看：

```text
正确性
相关性
完整性
事实一致性
幻觉率
格式遵循
安全性
延迟和成本
```

不能只看 BLEU、ROUGE 或一个 LLM Judge 分数。

## 六、推荐与搜索方向

### Q49. 召回和排序有什么区别？

- 召回：从海量候选中快速筛选一小部分，重点是覆盖率。
- 排序：对候选进行精细排序，重点是准确性。

常见链路：

```text
多路召回 → 粗排 → 精排 → 重排
```

### Q50. 双塔模型和 Cross-Encoder 有什么区别？

- 双塔：Query 和 Document 分别编码，向量可以提前计算，适合大规模召回。
- Cross-Encoder：Query 和 Document 一起输入模型，交互更充分，适合少量候选精排。

### Q51. NDCG 适合评估什么？

NDCG 适合评估排序结果，既考虑相关性，也考虑位置。越相关的结果排得越靠前，NDCG 越高。

### Q52. 负采样有什么作用？

训练推荐、搜索或 Embedding 模型时，负样本帮助模型区分相关和不相关内容。随机负样本通常比较简单，还需要加入难负样本提升区分能力。

## 七、训练与部署工程

### Q53. 混合精度训练有什么好处？

使用 FP16 或 BF16 做计算，使用 FP32 保存关键状态，可以在保证效果的同时降低显存占用并提高训练速度。

### Q54. GPU 显存不够怎么解决？

```text
减小 Batch 或序列长度
梯度累积
混合精度
激活重计算
LoRA/QLoRA
ZeRO/FSDP
模型量化
TP/PP 多卡并行
```

### Q55. 模型推理如何加速？

```text
量化
算子融合
FlashAttention
KV Cache
Continuous Batching
PagedAttention
TensorRT
CUDA Graph
模型蒸馏
```

具体采用哪种方法，要先确认瓶颈是计算、显存、带宽还是通信。

### Q56. ONNX Runtime、TensorRT、vLLM 怎么选？

- `ONNX Runtime`：通用、跨平台、兼容性好。
- `TensorRT`：NVIDIA GPU 上追求低延迟和高吞吐。
- `vLLM`：大语言模型在线推理和 API 服务。

### Q57. 模型部署的基本流程是什么？

```text
训练模型
→ 离线评估
→ 导出或转换格式
→ 推理性能测试
→ 封装 API
→ Docker 部署
→ 灰度发布
→ 监控和回滚
```

### Q58. 线上模型需要监控哪些指标？

```text
请求量和成功率
P50/P95/P99 延迟
GPU 利用率和显存
Token 消耗
模型输出质量
错误率和超时率
人工介入率
业务完成率
```

## 八、面试回答方法

建议按下面顺序回答：

```text
1. 先给一句定义
2. 再说核心原理
3. 最后说使用场景和局限
```

例如回答 `LoRA`：

> LoRA 是一种参数高效微调方法。它冻结原模型，只训练低秩矩阵，因此显存和训练成本更低，适合资源有限或需要快速迭代的场景。缺点是复杂任务的效果上限可能不如全参微调。

## 优先级建议

如果时间有限，优先准备：

```text
机器学习：过拟合、指标、逻辑回归、树模型、XGBoost
深度学习：反向传播、梯度问题、归一化、优化器、Attention、Transformer
CV：IoU、NMS、mAP、YOLO
NLP/LLM：BERT/GPT、LoRA、RAG、KV Cache
工程：混合精度、DDP、显存估算、模型部署和推理加速
```

企业面试官最终关注的不是“背了多少概念”，而是：

> 能不能解释原理，能不能根据数据和指标定位问题，能不能把模型稳定地训练、部署并产生业务效果。
