## 🛠 使用姿势

**一题一复盘：**
1. 先独立 AC，再看官方题解，把最优解思路以注释写进代码；
2. hard 题按 `simple → normal → hard` 层层拆解，不跳步；
3. 同类题型归类整理（分治、滑动窗口、状态机…），形成"题型 → 套路"映射。

**笔试复用模板：**
```python
# template.py —— 本地 AC 验证，直接复制到在线评测
input = sys.stdin.readline        # 快速读入
class Solution: ...
sol = Solution(); print(sol.solve(arr))
```

**面试前 30 分钟速查：**
1. `智能体高频50.md` + `AI_Agent面经.md` 过一轮高频题；
2. `RAG.md` / `LLM工具调用.md` 对着简历项目串一遍链路；
3. 面完立刻更新 `面经/` 对应文件，形成闭环。

> 题量是下限，复盘是上限。愿每道题都转化为 offer 的筹码。
